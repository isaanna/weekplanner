# personal – nur für euch

Persönliche Daten, die **nie weitergegeben** werden:

| Ordner | Inhalt |
| --- | --- |
| `settings/` | `brain.json`: verbotene Lebensmittel, Allergien, Vorlieben, Regeln |
| `plans/` | gespeicherte Wochenpläne (Portionen pro Person) |

**Gesundheitsdaten** – Profile (Gewicht, Größe, Alter), Tracking (was gegessen wurde) und Zyklus – liegen ausschließlich in der Datenbank der App und werden **nirgends** im Repository gespeichert, auch nicht hier.
